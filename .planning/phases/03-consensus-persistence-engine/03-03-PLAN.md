src/wal/record.rs
- enum RecordType { Preamble = 1, Entry = 2, Vote = 3, TruncateAfter = 4, Purge = 5, Committed = 6 }
- const RECORD_HEADER_LEN: usize = 9; const MAX_RECORD_LEN: u32 = 16 * 1024 * 1024
- fn encode_record(out: &mut Vec<u8>, ty: RecordType, payload: &[u8]) -> usize (bytes appended)
- fn decode_record(buf: &[u8]) -> Decoded<'_>;  enum Decoded<'a> { Record { ty: RecordType, payload: &'a [u8], consumed: usize }, End, Invalid }  (End = all-zero header, i.e. unwritten space; Invalid = bad length, short body, CRC mismatch or unknown type)
- Layout: [len u32 LE][crc32c u32 LE][type u8][payload]; len = 1 + payload.len(); crc32c covers len bytes, type byte, then payload.
- Entry payload = index u64 LE || body bytes. TruncateAfter payload = flag byte (0 = keep nothing, 1 = keep through) followed by u64 LE when flag is 1.
