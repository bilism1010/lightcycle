<objective>
Resolve R-1 and R-2 at the storage layer (decision D-09): make the Phase 2 index stamp-aware so a fuzzy snapshot plus replay is provably correct for single-key operations including CAS.

Purpose: naive replay of a fuzzy snapshot is wrong for CAS (counter-example in 03-RESEARCH.md R-1). Per-key apply-index stamping with skip-if-already-applied, tombstones that carry stamps, and a scan that drops only tombstones with stamp at or below the snapshot start index is the model-checked fix. This plan changes Phase 2 code and proves no read-path regression.

Output: stamped KvIndex and LocalEngine API (apply-at, scan, load-record), tests, and a reusable GET regression script. Multi-key transactions (FR-2 WATCH and multi-key conditionals) are explicitly out of scope: single-key stamping does not cover them (assumption A12) and a consistent-cut snapshot design must be reopened before any such operation is added.
</objective>

  <action>
In src/storage/index.rs replace `Slot { value: Atomic<Bytes> }` with `Slot { cell: Atomic<Versioned> }` where `Versioned { index: u64, value: Option<Bytes> }`. A never-written slot is a null pointer; a tombstone is a non-null Versioned whose value is None and whose index is its stamp. Update the Drop impl (exclusive access, epoch::unprotected, free any non-null pointer including tombstones).

Re-implement the existing public methods on the new cell with identical signatures and observable behavior, using stamp 0 for every write: get returns the cloned Some value or None; put swaps in Versioned { index: 0, value: Some }; delete returns true iff the prior cell held a Some value and leaves a tombstone cell; cas keeps every current semantic (insert-if-absent, expected None meaning absent for both null and tombstone, desired None meaning delete-to-tombstone, mismatch carries the observed value) and keeps the retry loop that reclaims its own allocation after a lost race; len counts only cells whose value is Some. Keep the epoch convention: epoch::pin(), Acquire loads, AcqRel swaps and compare_exchange, defer_destroy only on the unlinked old pointer, a SAFETY comment on every unsafe block.

Add enum AtStatus { Applied, Skipped }, `put_at`, and `stamp_of` per the interfaces block. put_at does get_or_insert_with a null slot, pins, and runs a compare_exchange loop: load the cell; if it is non-null and its index is greater than or equal to the entry index return Skipped before writing (re-check on every retry iteration); otherwise compare_exchange to a new Versioned { index, value: Some(value) }, defer_destroy the old pointer when non-null on success, and reclaim the owned allocation and retry on failure. Export AtStatus from src/storage/mod.rs.

In src/engine.rs add `ApplyOutcome` and `LocalEngine::set_at(index, key, value)`, which routes the value through the existing materialize (the only slab copy path) and calls put_at, mapping AtStatus to ApplyOutcome. Leave Command and apply_batch untouched (the Raft path uses its own request type in plan 03-05).

Update the module doc of index.rs: value and stamp swap as one pointer; tombstones carry stamps; the Raft apply path must use only the *_at methods while the stamp-0 legacy methods exist for Phase 2 callers and benches. Keep all existing tests unchanged. Add tests in the same mod: test_put_at_skips_stale_index (put_at 5 then put_at 5 and put_at 3 are Skipped and the value is unchanged; put_at 6 is Applied) and test_put_at_stamp_visible_via_stamp_of; in engine.rs add test_engine_set_at_skips_replayed_index.

  <behavior>

    - delete_at on an existing slot with stamp below index swaps in a tombstone stamped index (even if already a tombstone); with stamp at or above index returns Skipped

    - scan_versioned visits each key with one short pin, skips never-written slots, skips tombstones whose stamp is at or below the threshold, and hands the callback owned data with no pin alive
