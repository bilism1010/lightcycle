  <read_first>src/net/fake.rs and src/net/handler.rs (Task 1); openraft src/network/v2/network.rs stream_append and full_snapshot docs (cancel future, RPCOption::snapshot_chunk_size, soft_ttl); src/raft/types.rs SnapshotFile</read_first>
  <action>
Implement the rest of NetController and FakePeer per the interfaces block. Link control is directional state: drop_link(from, to) blocks that direction; partition(groups) blocks every pair whose endpoints are in different groups; isolate(node) blocks all links to and from that node; heal() clears all blocks; set_delay stores a Duration per directed link applied with tokio::time::sleep (tests use tokio::time::pause so delays cost no real time). There is no randomness anywhere. A call on a blocked link returns RPCError::Unreachable immediately. FakePeer::stream_append wraps the input stream so each request is delayed per the link, checks the link before forwarding (a link that goes down mid-stream ends the request stream so the output stream ends and openraft backs off), passes the wrapped stream to handler.stream_append, and returns its results in order; this is what exercises pipelined AppendEntries without sockets. append_entries, pre_vote and vote use the same link check. full_snapshot checks the link, applies the delay once, copies snapshot.snapshot.path with std::fs::copy into recv_dir as recv-<n>.tmp where n comes from an AtomicU64 in the controller (numeric-only names), calls handler.install_snapshot(vote, meta, SnapshotFile { path: copied, len }) and returns its response; it honors the cancel future by returning the StreamingError cancellation variant if it resolves first. new_heartbeat_client and new_snapshot_client return FakePeer values tagged Lane::Heartbeat and Lane::Snapshot, and stats() counts delivered and dropped calls per lane so tests can assert which lane carried a message. transfer_leader keeps the trait default.

Tests (#[tokio::test(start_paused = true)] where time matters): fake_partition_drops_both_directions_and_heal_restores, fake_isolate_blocks_all_links, fake_delay_preserves_stream_append_order (three requests, per-link delay, outputs in input order and virtual elapsed time at least the delay), fake_link_down_mid_stream_ends_output, fake_snapshot_copies_file_to_receiver_dir (tempfile source with known bytes; the stub sees a different path under recv_dir with identical bytes and the source file still exists), fake_heartbeat_and_snapshot_clients_use_distinct_lanes (stats show counts on the right lanes), fake_snapshot_cancel_returns_cancelled.
