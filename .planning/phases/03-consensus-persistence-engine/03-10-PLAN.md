<objective>
Milestone 3.4 file layer (decisions D-09, D-11; R-1 and R-2 applied): the fuzzy snapshot writer, reader, file format and on-disk store.

Purpose: this plan consumes the stamped scan from plan 03-02 and the R-1 proof from plan 03-05. Snapshot start index a is the threshold: live keys of any stamp are kept, tombstones with stamp greater than a are kept (dropping them is provably unsound), tombstones with stamp at or below a are dropped (R-2; this also compacts old tombstones on every restore or install). The file is plain frames so a byte range of the file can be sent as an InstallSnapshot chunk with no re-encoding (plan 03-09). The openraft RaftStateMachine integration is plan 03-12.

Output: src/snapshot/{format,writer,reader,store}.rs, a concurrent scan stress test, and updated snapshot/mod.rs.
